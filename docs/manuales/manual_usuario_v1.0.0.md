# Manual de Usuario v1.0.0

## Ejecución

```powershell
.\src\piedrapapelotijera.exe
```

## Opciones del Menú

1. **Jugar Partida** — Ingresa tu nombre y elige tu jugada (1: Piedra, 2: Papel, 3: Tijera)
2. **Ver Historial** — Muestra todas las partidas guardadas en disco
3. **Salir** — Cierra el programa

## Persistencia

Las partidas se guardan automáticamente en `src/historial_partidas.txt` y se conservan aunque cierres el programa.
